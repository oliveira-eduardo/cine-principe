Sobre o Projeto

    O sistema funciona via terminal e permite gerenciar as principais etapas de uma ida ao cinema:

    Cadastro: Registro do cliente.

    Consulta de Salas: Três salas diferentes com sessões e filmes gerados de forma automática.

    Compra de Ingressos: Escolha de assentos através de uma matriz (mapa da sala) e geração de bilhete.

O que foi usado

    Linguagem: Java.

    POO: Classes, objetos, encapsulamento (private/public) e métodos.

    Estrutura de Dados: Uso de arrays e matrizes para os assentos e horários.
